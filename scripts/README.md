# Υποβολή προτάσεων στο GitHub

Η υπηρεσία ανοίγει τις τέσσερις δραστηριότητες από τον υπολογιστή του εκπαιδευτικού. Όταν μια ομάδα πατήσει **Υποβολή πρότασης**, η υπηρεσία αποθηκεύει ένα αρχείο κειμένου στο ιδιωτικό `GiorgosBouh/movable_school_submissions`.

Χρειάζονται Python 3.9 ή νεότερη, GitHub CLI (`gh`), σύνδεση στο GitHub στον υπολογιστή του εκπαιδευτικού και κοινό τοπικό δίκτυο για τις ομάδες. Ο λογαριασμός GitHub πρέπει να έχει δικαίωμα εγγραφής στο ιδιωτικό αποθετήριο.

1. Άνοιξε το Terminal στον φάκελο του αποθετηρίου `movable_school`.
2. Βρες την ιδιωτική IPv4 του υπολογιστή από τις ρυθμίσεις του δικτύου και εκτέλεσε την εντολή, βάζοντας τη δική σου διεύθυνση στη θέση του παραδείγματος.

   ```sh
   python3 scripts/submissions.py --host 192.168.1.25
   ```

3. Δώσε στις ομάδες τον **Σύνδεσμο τάξης** και τον **Κωδικό μαθήματος** που εμφανίζονται στο Terminal. Κάθε ομάδα ανοίγει τη δραστηριότητά της από αυτόν τον σύνδεσμο. Στο τέλος πατά **Ετοιμάστε την τελική πρόταση**, εισάγει τον κωδικό και πατά **Υποβολή πρότασης**.
4. Οι προτάσεις εμφανίζονται στο GitHub στη διαδρομή `submissions/ΕΕΕΕ-ΜΜ-ΗΗ/lesson-02/<δραστηριότητα>/<αναγνωριστικό>.txt`. Η ημερομηνία είναι εκείνη της έναρξης του μαθήματος, σε ώρα Ελλάδας. Πάτησε Ctrl+C στο Terminal όταν τελειώσει η υποβολή.

Οι ομάδες δεν χρειάζονται λογαριασμό GitHub. Χρησιμοποίησε την υπηρεσία μόνο στο δίκτυο της τάξης και ζήτησε από τις ομάδες να γράφουν μόνο το κείμενο της πρότασης, χωρίς ονόματα ή άλλα προσωπικά στοιχεία. Οι δημόσιοι σύνδεσμοι GitHub Pages παρέχουν τη δραστηριότητα και αντιγραφή κειμένου.
